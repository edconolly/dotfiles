# Brand directions (SKILL.md step 7)

Directions are for the **brand layer only**: the website, the tone of voice, the page end users meet, and a few
signature moments inside the product (an empty state, a report export). The product layer has one proposal,
judged on craft (SKILL.md step 6); brand directions sit on top of it and must not redesign how the product works.

Why the split: earlier versions spread every proposal across form and personality axes, product included. That
fixed sameness (rounds 1 and 2 on Bot Max) but produced products that were different and worse: unfamiliar
layouts, display faces in tables, metaphors the user had to decode. Variety is valuable where buyers form an
impression; it is a cost where people work.

## What directions vary
| Axis | Options |
|---|---|
| Idea / positioning | A promise the product can actually make (from the user's notes, or proposed and marked as a hypothesis in the description, never in the design) |
| Mood | The feeling in a few words: e.g. calm authority, quick and bright, warm and local, technical and exact |
| Colour mood | light neutral · light tinted · mid-tone or saturated brand ground · dark neutral · dark tinted · high-contrast black and white. Name the band and 3–5 hex colours |
| Type pairing | A display or headline face for the brand, paired with the product's UI face. Name both; the class of the display face should differ between directions |
| Tone of voice | A named tone with three sample lines: a website headline, an error, a status message. Product truths (exact status words, claims we can't make) stay fixed |
| Website composition | centred statement · full-bleed product image · editorial long-read · product demo first · data story · comparison first |
| Signature moment | One memorable thing that does a real job, used in a few places (e.g. the verdict shown as a receipt in reports, a calm empty state with the day's first visitors) |
| Imagery | Product screenshots, diagrams, photography, illustration, type only |
| Market position | How it looks unlike the competitors in the audit, in one line |

Spread rules for a set of 2–3: no two directions share both colour mood band and display type class; each
differs from the others in at least two of mood, colour mood, type pairing, tone and website composition; each
names its difference from the competitors.

**Status and data colours belong to the product layer.** They carry meaning users learn, so brand directions
use the product proposal's values unchanged. If a direction's palette clashes with them, the direction changes,
not the status colours. Flag a real conflict to the user instead.

**Logos are out of scope** until the name is final. Every direction uses a plain text wordmark (the name in its
display face). Improvised marks suggest a brand that doesn't exist yet.

**No concept-first dressing.** A metaphor can inspire a mood or a signature moment; it must not turn screens into
props (fake paper, stamps on every row, a referee's cards meaning the opposite of what users expect). If the
direction only works by renaming the product's things, drop it.

## Description format (show the user before building)
**Name** (one or two words)
**The idea**: 2–3 plain sentences the user can picture: what it feels like and why it fits the product.
- Idea it carries · Mood · Signature moment · Imagery
- **Colour**: band + 3–5 named hex colours (status colours: the product's, unchanged)
- **Type**: display face + the product's UI face
- **Tone**: its name + three sample lines
- **Website**: composition, and what the first screen shows
- **Inside the product**: which signature moments it touches (at most two or three), and nothing else
**How it differs**: from the other directions and from the competitors, one line each.

Keep a set under ~500 words. Draft with a subagent, then review it yourself before the user sees it: a table of
the set (colour band, display class, tone, composition), generic colours (cream + terracotta, black + acid), claims
the product can't back, false "only one that…" lines, and real product names described inaccurately. Then wait
for the user to choose, edit or ask for another set. Further rounds continue the lettering (D, E, F…).
